How it works

  1. Tokenize: the text is split into words (letters and combining marks).
  2. Script detection: each word is mapped to a Unicode block (Devanagari, Arabic, Telugu, Tamil, Bengali or Latin). Scripts with one supported language are resolved immediately.
  3. Shared scripts: Latin (English, Hinglish, Spanish, French) and Arabic script (Urdu, Arabic) need statistics. Words are split into character trigrams and scored with Naive Bayes using add-0.5 smoothing.
  4. Code-mixing: every Latin word is classified separately, so a sentence like “kal meeting hai, please be on time” is tagged word by word.

Limitations: the training corpus is small, so very short words can be misclassified. Marathi and Nepali share the Devanagari script with Hindi and are reported as Hindi. “Hinglish” covers Romanized Hindi/Urdu.
